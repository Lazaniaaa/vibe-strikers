# Toy Town · творчий M3

Чотири повні MapData: `toy-town-l1-r1`, `toy-town-l1-r2`, `toy-town-l2-r1`, `toy-town-l2-r2`.
Вихідний `toy-town` залишається M2 до вибору власника. LEFT / RIGHT — маршрути +Z / −Z;
дзеркальність командних половин — за X. Формат даних і сигнатури API збережено.

- L1: керамічні майстерні, послідовні кімнати, двір доставки.
- L2: відкрита сортувальна зала, експедиція, поштовий ліхтар на даху.
- R1: відкритий ринок, смугасті тенти, арка й сцена +0,6 м.
- R2: критий лимонадний павільйон, зелені острівці та тераса +0,6 м.

[Прев’ю](http://127.0.0.1:5174/?map=1) має незалежні селектори флангів, порівняння з M2,
обидві палітри, план кімнат без дахів, теплокарту та шість нових камер на рівні очей.
Нові камери використовують FOV 70; початкові чотири експортні ракурси — FOV 42.
Висота камери на терасі: 0,6 + 1,6 м. Shadow normalBias у прев’ю збільшено до 0,08,
щоб прибрати self-shadow acne; світло й палітра в MapData не змінювались.

## Перевірка

```text
node src/maps/verify.mjs
npm run build
```

`verify.mjs` спочатку перевіряє незмінний M2 (31 перевірка), потім усі чотири M3
(по 30 перевірок). Лише M2: `node src/maps/verify.mjs --m2-only`.
Генератор альтернатив: `python src/maps/tools/design_m3.py`.
Свідома зміна SHA-базових значень: `node src/maps/verify-m3.mjs --write-baseline`;
запис дозволено лише після успішної перевірки всіх чотирьох комбінацій.

Захищені джерела персонажів/зброї та публічне API порівнюються з архівами попередніх
схвалених етапів у `outputs/`. Вони вже є в робочому проєкті.

[Повний звіт, таблиці й PNG](../../outputs/toy-town-m3/REPORT.md).
У ньому окремо наведено ризики повторного M2-аудиту: поперечні простріли через центр
до 56 м та незахищені клітини перших трьох секунд. Контракт M3 перевіряє окремо
простріли всередині редагованих флангів (≤25 м) та огляд кожного спавну (≤40 м).
Ці різні метрики не підмінюють одна одну.
